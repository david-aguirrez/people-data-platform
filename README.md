# People Data Platform

End-to-end workforce analytics platform demonstrating modern people-data engineering practices.

## Objectives
- Build historical employee snapshots
- Model organizational hierarchies
- Track promotions, transfers, and attrition
- Implement data quality tests
- Publish workforce metrics for self-service analytics

## Planned Stack
- SQL
- dbt
- Snowflake
- Python
- Power BI
- GitHub

## Repository Structure
- `/sql` – exploratory and analytical SQL
- `/dbt` – transformation models
- `/python` – validation and ingestion scripts
- `/docs` – architecture diagrams and metric definitions
- `/powerbi` – dashboard assets
